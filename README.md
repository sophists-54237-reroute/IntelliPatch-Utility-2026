### Will using OmniPatch get my account banned?

OmniPatch modifies local application files and does not interact with official servers. While account bans are extremely unlikely, this tool operates in a legal gray area.

### Do I need an internet connection to use the patch?

You need an internet connection to download OmniPatch and potentially to apply updates for the tool itself. The patched applications may require internet for normal operation, but the patch works offline.

### What are the system requirements?

OmniPatch requires Windows 10 or Windows 11. It needs administrator privileges to apply the patch files to the protected application directories.

### Can I use OmniPatch on multiple computers?

Yes. OmniPatch is a portable tool. You can copy the executable to any compatible Windows machine and run it without installation.

### How do I revert the changes or uninstall OmniPatch?

OmniPatch creates backups of original files before patching. The tool includes an 'Unpatch' or 'Restore' feature to revert all changes to their original state.
